# Use a small Validation Index on project containers

Ordinary validation and cleanup should use a versioned **Validation Index** stored in shared plugin data on project-owned containers. The v1 index is a small list of known IDs: **Subject Nodes**, **Annotation Cards**, **Annotation Badges**, **Flow Endpoints**, **Context Frames**, **Owner Context Frames**, **Flow Connector** visual roots, and **Connector Obstacle** candidates. It is maintained through **Figma File Operation Batches** using a runtime writer operation that resolves created-node refs to real Figma node IDs before merging the index.

The index does not replace the records from ADR 0044. Complete **Annotation** records remain on **Annotation Card** roots, complete **Flow Connector** records remain on **Flow Connector** visual roots, reverse references remain small values on bound nodes, and validation reports remain runtime-only. The index only tells validation and cleanup which known project-owned nodes are worth checking, so ordinary paths do not need page-wide shared-plugin-data discovery.

Container-level storage follows ADR 0043: core defines the schema and emits runtime-neutral operation batches, while the app runtime applies those operations through the Figma writer seam. The first v1 index may exist on the **FFA Annotations** container, the **FFA Connectors** container, or both, because each authoring domain can update its own known IDs without reading unrelated records or duplicating complete semantic data.
