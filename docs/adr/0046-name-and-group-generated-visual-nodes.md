# Name and group generated visual nodes

The first demo creates readable page-level containers and visual node names while treating shared plugin data as the only semantic source of truth. The current page should contain `FFA Annotations` for **Annotation Cards** and **Annotation Badges**, and `FFA Connectors` for **Flow Connector** visual nodes. Annotation card roots are named `FFA Annotation Card #<number>`, badge roots are named `FFA Annotation Badge #<number>`, and connector roots are named `FFA Connector <startName> -> <endName>`. All project-created roots and containers write the shared-plugin-data `kind` key; validation and extraction must use shared plugin data records and references rather than node names, so designer renaming does not change semantics. Layering remains consistent with the project visual stack: **Context Frames**, page-level **Flow Connectors**, **Annotation Cards**, then **Annotation Badges**.
