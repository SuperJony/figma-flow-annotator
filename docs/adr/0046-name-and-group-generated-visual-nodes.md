# Name generated visual roots

The first demo creates readable page-level visual root names while treating shared plugin data as the only semantic source of truth. **Annotation Card**, **Annotation Badge**, and **Flow Connector** roots live directly under the current page instead of inside generated `FFA Annotations` or `FFA Connectors` grouping frames. Annotation card roots are named `FFA Annotation Card #<number>`, badge roots are named `FFA Annotation Badge #<number>`, and connector roots are named `FFA Connector <startName> -> <endName>`. All project-created visual roots write the shared-plugin-data `kind` key; validation and extraction must use shared plugin data records and references rather than node names, so designer renaming does not change semantics. Layering remains consistent with the project visual stack: **Context Frames**, page-level **Flow Connectors**, **Annotation Cards**, then **Annotation Badges**.
