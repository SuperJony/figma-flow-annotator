# Use a three-tab plugin UI for first demo

The first demo plugin UI follows the reference in `docs/plugin-ui 参考.png`: a persistent **Flow Annotator** panel with **Annotate**, **Connect**, and **Validate** tabs. **Annotate** contains create/add/arrange annotation workflows, **Connect** contains endpoint preview, swap, existing connector status, flow action, connector creation, and routing status, and **Validate** contains validation summary, filters, issue list, and stale-index cleanup. This groups the nine first-demo commands by user workflow instead of exposing a flat command list.
