# Build a small TypeScript router first

The first demo should implement a small project-owned TypeScript router instead of adopting a full diagram SDK or a WASM/LGPL router dependency. Existing tools such as libavoid, JointJS, yFiles, AntV X6, and React Flow Smart Edge are useful references and benchmarks, but this plugin needs only route points for custom Figma Design visual nodes plus project-specific semantics such as shared plugin data, context-frame/card obstacles, badge exclusion, explicit refresh, and same-target connector trunks.
