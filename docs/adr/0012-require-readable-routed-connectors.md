# Require readable routed connectors

**Flow Connectors** prioritize extractable structure, but the visual route must still meet a standard diagram readability bar. The first demo should route connectors around intervening **Context Frames** and **Annotation Cards** instead of drawing through them, because a connector from frame 1 to frame 3 in a horizontal sequence must not cross frame 2 even when the start and end structure is correct. **Annotation Badges** are not routing obstacles, but they should render above connectors so anchors remain visible.
