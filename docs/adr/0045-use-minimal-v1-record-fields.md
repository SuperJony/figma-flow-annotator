# Use minimal v1 record fields

The first demo uses minimal versioned **Annotation** and **Flow Connector** records. An **Annotation** record contains `schemaVersion`, `id`, `annotationNumber`, optional `title`, required `body`, optional `kind`, `contextFrameId`, `subjectNodeIds`, `createdAt`, and `updatedAt`. For proof-of-concept annotations, `contextFrameId` stores the owning **Context Frame** ID or the current page ID when the page acts as a **Temporary Page Context**. A **Flow Connector** record contains `schemaVersion`, `id`, `start: { nodeId, contextFrameId }`, `end: { nodeId, contextFrameId }`, `ownerContextFrameId`, `flowAction: string | null`, optional `routeCache`, `createdAt`, and `updatedAt`. Records do not store their own visual root node IDs because the record is already stored on that Figma visual root; callers can read the containing Figma node ID when needed.
