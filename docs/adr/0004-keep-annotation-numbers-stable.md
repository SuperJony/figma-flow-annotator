# Keep annotation numbers stable

**Annotation Numbers** are scoped to the owning annotation context and are not automatically compacted when an **Annotation** is deleted. The owning context is normally a **Context Frame**; when selected **Subject Nodes** do not share one, the current page may act as a **Temporary Page Context** for the proof of concept. Stable numbers protect references in badges, review discussions, screenshots, and agent output; any later renumbering should be an explicit command rather than a deletion side effect.
